#    opencv-python=cp37-abi3、PySide6=cp310-abi3、numpy 有 cp313。

# ── 约束 2：mediapipe 必须 `--no-deps` 安装，并**跳过 opencv-contrib-python**
#    mediapipe 声明依赖 opencv-contrib-python，而它与 opencv-python 同时提供 cv2。
#    pip 替换时会删除 site-packages\cv2 下几千个文件 —— 在受限环境下会撞上
#    批量删除护栏而中断安装。opencv-python 已经够用：
#    已实测原生推理管线跑通（首次 17ms / 30 帧均值 15.2ms），不需要 contrib。
#    pip 事后会报一条 "mediapipe requires opencv-contrib-python" 的提示，**可以忽略**。
#
# ── 约束 3：装 `PySide6-Essentials`，**不要**装 `PySide6` 元包
#    原因见下方"界面"一节包注释（Addons 覆盖 Essentials 的既有文件，
#    pip 连续 unlink 满 50 次即触发批量删除护栏、安装被中断）。
#

# 界面
# ⚠️ 装 Essentials，**不要**装 PySide6 元包（会连带 PySide6-Addons）。
#    原因：6.x 起 PySide6 拆成 Essentials + Addons 两个 wheel，两者都写进
#    同一个 site-packages\PySide6\ 目录，Addons 覆盖 Essentials 既有文件时
#    会让 pip 连续 os.unlink（pip 全文件唯一一处 unlink 就是这个覆盖分支），
#    实测达 50 次即触发本机批量删除护栏、安装被 SystemExit 中断。
#    本项目只用 QtWidgets / QtGui / QtCore，全在 Essentials 里（已实测导入通过）。
PySide6-Essentials==6.11.2      # Qt 官方绑定；圆角大按钮 / 平滑中文都靠它

# 推理

numpy==2.5.3
